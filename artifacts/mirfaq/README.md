# مِرفق — منصة إدارة صيانة العقارات

**صيانة عقارك، بوضوح وسهولة**

منصة SaaS عربية متكاملة لإدارة بلاغات الصيانة في المجمعات السكنية والتجارية بالمملكة العربية السعودية.

## المتطلبات
- Node.js 18+
- pnpm

## التشغيل المحلي

```bash
# نسخ متغيرات البيئة
cp .env.example .env

# تثبيت الحزم
pnpm install

# تشغيل التطبيق
pnpm --filter @workspace/mirfaq run dev
```

## الصفحات

| المسار | الوصف |
|--------|-------|
| / | الصفحة الرئيسية |
| /login | صفحة اختيار الدور |
| /manager | لوحة تحكم مدير العقار |
| /resident | لوحة تحكم الساكن |
| /technician | لوحة تحكم الفني |
